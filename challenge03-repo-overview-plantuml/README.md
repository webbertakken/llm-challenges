# Challenge 03 — Repo Overview with PlantUML

**Difficulty:** Intermediate
**Topics:** Documentation, PlantUML, software architecture, Markdown

---

## Objective

Analyse this repository and create the best possible overview diagram using PlantUML. Embed the diagram in a Markdown file.

## Requirements

- Study the repo structure, files, and relationships
- Create a PlantUML diagram that gives a clear, informative overview of the repo
- Choose whatever diagram type(s) best convey the structure (component, class, package, etc.)
- Embed the diagram in a Markdown document with a brief written explanation
- Use `!theme blueprint` for the diagram theme
- Do **not** include solution result folders in the diagram — only show the repo structure, challenges, and their specifications
- Do **not** list individual challenges — represent them generically (e.g. `challengeNN-<slug>/`) so the diagram remains valid as new challenges are added

## Deliverables

1. `overview.puml` — The PlantUML source file
2. `overview.md` — A Markdown file that embeds/references the diagram and includes a short explanation of the repo structure

## Evaluation Criteria

- **Accuracy:** Does the diagram faithfully represent the repo?
- **Clarity:** Is it easy to understand at a glance?
- **Completeness:** Are the key components and relationships captured?
- **Presentation:** Is the Markdown well-written and the diagram well-formatted?
