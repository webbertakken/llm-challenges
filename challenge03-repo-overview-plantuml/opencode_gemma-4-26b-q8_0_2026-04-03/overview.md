# Repository Overview

This repository contains a series of TypeScript benchmark challenges for LLM agents. Each challenge is organized into its own directory, containing a `README.md` with specifications and a results folder for each agent's solution.

## Structure

The repository structure is as follows:

- `INSTRUCTIONS.md`: General instructions for LLM agents.
- `README.md`: Main repository overview.
- `package.json` / `package-lock.json`: Project dependencies and configuration.
- `challengeNN-<slug>/`: Individual challenge directories.
    - `README.md`: Challenge-specific instructions and requirements.
