# Repository Overview

This repository contains a series of TypeScript benchmark challenges designed to evaluate the capabilities of Large Language Models (LLMs). Each challenge focuses on different aspects of programming, from deep read-only types to complex system simulations and architectural documentation.

## Structure

The repository is organized as follows:

- **Root Directory**: Contains global instructions, the main README, and configuration files.
- **Challenges**: Each challenge is contained in its own directory (e.g., `challengeNN-<slug>/`).
  - Each challenge directory includes a `README.md` with specific requirements and deliverables.
  - Results from various LLM runs are stored within subdirectories inside each challenge folder.
