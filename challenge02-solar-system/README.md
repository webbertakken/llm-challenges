# Challenge 02 — Solar System in p5.js

**Difficulty:** Intermediate
**Topics:** Creative coding, animation, p5.js, physics simulation

---

## Objective

Write a solar system simulation using p5.js.

## Requirements

- A central sun with orbiting planets
- Planets should orbit at different speeds and distances
- Include at least the 8 major planets with roughly proportional sizes and distances
- Moons orbiting at least 2 planets
- Smooth animation
- Visually appealing — use colors, glow effects, or other styling

## Deliverables

1. `index.html` — Entry point that loads p5.js (via CDN) and your sketch
2. `sketch.js` — The p5.js sketch

## Evaluation Criteria

- **Visual quality:** Does it look good?
- **Accuracy:** Reasonable representation of the solar system
- **Code quality:** Clean, readable code
- **Creativity:** Bonus for extras like rings, asteroid belts, starfield backgrounds, zoom/pan controls
